### Datos solicitados

Nombre; correo o teléfono de contacto; sede/área; descripción del incidente; y datos técnicos del equipo estrictamente necesarios para atenderlo. **No solicite contraseñas, números de tarjetas, datos biométricos o información sensible por este formulario.** Si el caso requiere datos sensibles, documente aparte necesidad, base legal, acceso restringido y autorización explícita.

### Finalidad y conservación

Usaremos los datos para crear y hacer seguimiento al ticket, contactar al titular para resolver el caso, documentar la solución y cumplir obligaciones legales o contractuales aplicables. No se usarán para publicidad ni se compartirán con terceros para fines propios sin una base válida e información previa. Se conservarán durante [plazo definido por tabla de retención aprobada] y después se suprimirán o anonimizarán, salvo obligación legal o contractual de conservarlos.

### Consideraciones para implementación

- Enlazar la política desde el formulario, con un enlace descriptivo y accesible.
- Si el servicio puede prestarse sin un dato opcional, no usar la negativa como barrera.
- Diferenciar la autorización necesaria para soporte de cualquier consentimiento opcional de mercadeo.
- No pedir información sensible para un ticket ordinario. Si excepcionalmente se requiere, informar carácter sensible, facultad de no responder y fundamento aplicable.
- En casos de menores, adaptar la información, aplicar salvaguardas reforzadas y obtener las autorizaciones requeridas.
- Alinear los plazos y canales con la política aprobada y la normativa vigente. Esta plantilla no sustituye revisión jurídica.
